🧩 Keep your Claude artifacts here

Anything Claude builds for you (an interactive explainer, a diagram, a custom quiz) can live in this library next to the slides.

Option 1: save the HTML file

  1. Save the artifact as an .html file into exams/kcna/library/, e.g. service-types.html.
  2. Add an entry to the library list in exams/kcna/exam.js: 
    { group: 'My artifacts', icon: '🧩', kind: 'page',
  title: 'Service types explained', url: 'library/service-types.html' }
  3. Commit and push. It opens inside the hub (and in a new tab).

Option 2: link a published artifact

{ group: 'My artifacts', icon: '🔗', title: 'Scheduling visualiser',
  url: 'https://claude.ai/…' }

Option 3: turn it into a chapter

Ask Claude to “add slides / questions to the KCNA <chapter> chapter following CONTENT_GUIDE.md”, then run node tools/validate.js kcna.
